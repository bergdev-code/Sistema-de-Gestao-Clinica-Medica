# 🏥 Sistema de Gestão para Clínica Médica

Projeto desenvolvido para a disciplina de **Garantia e Qualidade de Software**, com o objetivo de criar um sistema para gerenciamento de uma clínica médica.

## 📌 Funcionalidades

- Cadastro e gerenciamento de pacientes.
- Cadastro de médicos e especialidades.
- Agendamento, remarcação e cancelamento de consultas.
- Gerenciamento de prontuários médicos.
- Cadastro e gerenciamento de exames.
- Controle financeiro e pagamentos.
- Controle de acesso por perfil de usuário.

## 🔒 Qualidade e Segurança

O projeto também contempla:

- Segurança e proteção de dados conforme a LGPD.
- Controle de acesso aos prontuários.
- Desempenho e usabilidade.
- Logs de auditoria.
- Testes unitários, integração, sistema e segurança.

## 🧪 Testes e Validação

Desenvolvimento de um Plano de Qualidade e um Plano de Testes para garantir o funcionamento e a confiabilidade do sistema.
